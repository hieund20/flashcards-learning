A Progressive Web App (PWA) for TOEIC vocabulary learning, built with Angular and Angular Material. It includes interactive flashcards, quizzes, favorites, and a retention system for spaced-repetition review.


Current Features
- Flashcards — Learn vocabulary with words, meanings, examples, types, levels, and categories.
- Retention / Review — Add difficult words to a review system and practice them later.
- Quiz — Test vocabulary knowledge and track correct and incorrect answers.
- Favorites — Save words for quick access.
- Review Progress — Track cards due for review and review results.
- PWA — Install and use the application like a mobile app.
- Dark Mode — Supports a dark UI theme.
- Responsive UI — Designed for both desktop and mobile.
